# Описание моделей устройств

Для добавления/удаления/изменения устройств необходимо редактировать файл `device.json`
Необзодимо правильно указывать типы устройств и правильно задавать их структуру.

## Примеры с описаниями полей

### тип `Room`

Комната, может содержать другие устройства и комнаты, используется для навигации.

```json
{
  /** Идендификатор  комнаты, нужен для навигации в URL-е, ВАЖНО! Лучше делать его уникальным для каждой команты*/
  "id": "first_room",
  /** Тип элемента, для комнаты тут всегда должен быть 'Room' */
  "type": "Room",
  /** Название которое будет отображено пользователю */
  "label": "1-ый этаж",
  /** Массив  всех  устройств и комнат */
  "children": []
}
```

### тип `WB_MR6C_Q`

одно реле в 6-и канальном реле

```json
{
  /** Тип элемента, всегда должен быть 'WB_MR6C_Q' */
  "type": "WB_MR6C_Q",
  /** Название которое будет отображено пользователю */
  "label": "1-ый этаж",
  /** адрес реле в контроллере, в данном примере реле с 13 модбас адресом */
  "mqttDeviceAddr": "wb-mr6c_13",
  /** канал управления, проще говоря адрес реле "выхода", в данном примере первое реле  */
  "chanelId": 1
}
```

### тип `LightGroup`

Группа света для связки Основной/Дежурный, загарается только тогда когда включены все реле в группе.
Переключает все реле в группе исходя из состяния этой группы

```json
{
  /** Тип элемента, всегда должен быть 'LightGroup' */
  "type": "LightGroup",
  /** Название которое будет отображено пользователю */
  "label": "Основной",
  /** массив реле которые входят в группу, необходимо указывать массив из WB_MR6C_Q устройств */
  "coils": [
    {
      "type": "WB_MR6C_Q",
      "label": "Основной",
      "mqttDeviceAddr": "wb-mr6c_13",
      "chanelId": 1
    },
    {
      "type": "WB_MR6C_Q",
      "label": "Дежурный",
      "mqttDeviceAddr": "wb-mr6c_13",
      "chanelId": 2
    }
  ]
}
```

### тип `SimpleLightGroup`

Группа для управления Основной/Дежурный. Загорается тогда когда включены все реле из массива `simpleCoils`.
При нажатии выключает все реле из массива `mainCoils` и переключает состояние в `simpleCoils`.
Своё состояние считает по массиву `simpleCoils`. Группа активна когда ВСЕ катушки в массиве активны.

```json
{
  /** Тип элемента, всегда должен быть 'SimpleLightGroup' */
  "type": "SimpleLightGroup",
  /** Название которое будет отображено пользователю */
  "label": "Дежурный",
  /** массив реле на отключение, необходимо указывать массив из WB_MR6C_Q устройств */
  "mainCoils": [
    {
      "type": "WB_MR6C_Q",
      "label": "Основной",
      "mqttDeviceAddr": "wb-mr6c_82",
      "chanelId": 1
    }
  ],
  /** массив реле на переключение, необходимо указывать массив из WB_MR6C_Q устройств */
  "simpleCoils": [
    {
      "type": "WB_MR6C_Q",
      "label": "Дежурный",
      "mqttDeviceAddr": "wb-mr6c_82",
      "chanelId": 2
    }
  ]
}
```

### тип `CurtainGroup`

Элемент для управления группой штор

```json
{
  /** Тип элемента, всегда должен быть 'CurtainGroup' */
  "type": "SimpleLightGroup",
  /** Название которое будет отображено пользователю */
  "label": "Шторы",
  /** массив из штор для управления, нет ограничений на количество*/
  "children": [
    {
      /** Тип элемента, всегда должен быть 'Curtain' */
      "type": "Curtain",
      /** адрес группы для шторы, в нашем проекте у всех 1 */
      "groupId": 1,
      /** адрес канала шторы */
      "chanelId": 1
    },
    {
      /** Тип элемента, всегда должен быть 'Curtain' */
      "type": "Curtain",
      /** адрес группы для шторы, в нашем проекте у всех 1 */
      "groupId": 1,
      /** адрес канала шторы */
      "chanelId": 2
    }
    ....
  ]
}
```
